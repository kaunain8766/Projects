Rock Paper Scissors

A Java console-based game for two players.

Game Rules

  • R beats S
  • S beats P
  • P beats R

How It Works

The game runs for 3 rounds. Each player enters:
R = Rock, P = Paper, S = Scissors

Technologies Used

Java, Scanner Class, Conditional Statements

How to Run

javac Main.java
java Main
